# GRUNVALDLAB — начальный реестр дефектов и защит

В каждом проекте дополнять edit/MISTAKES.md реальными ошибками, с проверкой исправления.

| Дефект | Профилактика / контроль |
|---|---|
| Начало с половины слова / без вступления | Сначала построить хук, проверить аудио первых 3 секунд |
| Конец фразы отрезан | Word-level границы + запас + прослушивание склеек |
| Несвязанные короткие вырезки | Монтаж по законченным мыслям, не по паузам |
| Говорящая голова выглядит статично | Смена крупности, B-roll, интерфейс или схема по смыслу |
| Неполноэкранное видео со случайной подложкой | Выбрать full-screen или осмысленный PiP и единый композиционный фрейм |
| Вымышленный логотип ServGo | Использовать подтвержденные бренд-файлы, иначе временный текст |
| Субтитры за краями кадра | Проверка безопасных зон и мобильного 9:16 |
| Музыка перекрывает голос | Voice-first баланс, автоматизация громкости, проверка слухом |
| Эффекты мешают пониманию | Убирать элементы без смысловой функции |
| Первый рендер не соответствует раскадровке | Проверить кадры до полного рендера |
| Долгий/дорогой рендер без необходимости | Начать с CPU; GPU брать лишь при обоснованной потребности |
| Повтор прошлых ошибок | Перед каждой задачей прочитать edit/MISTAKES.md |

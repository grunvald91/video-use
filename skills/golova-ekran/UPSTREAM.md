# Происхождение «Голова + экран»

В этот каталог перенесён открытый скилл Константина Васина из https://github.com/vasin-k-i/golova-ekran (ветка main, tree `84ba18d6e3ca41c0e54ba5c57a5b6ea2bf087a7e`, проверено 12 октября 2026).

Оригинальная лицензия — MIT; см. `LICENSE`. Файлы в каталоге `scripts/`, `references/`, `assets/` и `SKILL.md` сохранены из исходного репозитория.

После клонирования в рабочее окружение проверьте зависимости:

```bash
python3 skills/golova-ekran/scripts/montage.py check
```

Для работы потребуются ffmpeg/ffprobe, Python (Pillow, NumPy) и whisper.cpp с моделью для расшифровки оговорок. Поскольку скрипты сторонние, перед выполнением требуются проверка среды, разрешений и зависимостей; никакие сторонние установочные команды автоматически не запускаются.
